FAQ

Pertanyaan yang sering ditanya

Bagaimana cara join server AeroBlast?

Buka Minecraft lalu pilih Multiplayer → Add Server dan masukkan:

IP · aeroblast.my.id Port · 25543

Mendukung Java Edition (1.20–1.21+) dan Bedrock / PE. Untuk Bedrock, masukkan IP dan port secara terpisah di menu External Server.

Versi Minecraft berapa yang didukung?

AeroBlast mendukung Java Edition 1.20 hingga 1.21+ dan Bedrock / Pocket Edition versi 1.21.11+. Jika ada masalah versi, coba update Minecraft kamu ke versi terbaru.

Kenapa saya tidak bisa masuk server?

Coba periksa hal berikut:

• Pastikan IP dan Port sudah benar: aeroblast.my.id : 25543
• Cek status server di halaman utama — mungkin sedang maintenance.
• Pastikan koneksi internet kamu stabil.
• Jika kamu menggunakan VPN, coba matikan dulu.
• Jika masih tidak bisa, kemungkinan akunmu terkena ban — hubungi Admin.

Kenapa saya kena kick atau ban?

Ada beberapa kemungkinan penyebabnya:

• Kick otomatis — tidak aktif terlalu lama (AFK tanpa pool), atau koneksi terputus.
• Ban sementara — melanggar rules seperti spam, toxic, atau griefing.
• Ban permanen — cheat, exploit bug, atau pelanggaran berat lainnya.

Jika merasa tidak melanggar, hubungi Admin melalui WhatsApp atau Discord untuk klarifikasi dan proses banding.

Apakah ada backup data pemain?

Ya, server AeroBlast melakukan backup data secara berkala. Namun item yang hilang akibat kelalaian pemain sendiri (misal: jatuh ke lava, terkena mob) tidak bisa dikembalikan. Backup hanya digunakan untuk pemulihan server jika terjadi crash atau error teknis.

Berapa lama item pesanan saya masuk?

Item otomatis masuk dalam 1–10 menit setelah pembayaran berhasil. Jika ada kendala, segera lapor ke Discord.

Metode pembayaran apa saja yang tersedia?

Tersedia DANA, GoPay, dan QRIS (bisa dibayar dari semua e-wallet dan mobile banking yang mendukung QRIS).
